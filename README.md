# yvideo 🐱

Site paródia (humor) recheado de vídeos reais de gatos do YouTube.

## Como colocar no ar (GitHub Pages)

1. Crie uma conta gratuita em https://github.com (se ainda não tiver).
2. Clique em **+** (canto superior direito) → **New repository**.
   - Nome: `yvideo` (ou o que preferir)
   - Marque como **Public**
   - Clique em **Create repository**
3. Dentro do repositório, clique em **Add file → Upload files** e envie o arquivo **`index.html`** (já está com esse nome, não precisa renomear).
4. Role até o final e clique em **Commit changes**.
5. Vá em **Settings → Pages** (menu lateral).
   - Em **Branch**, selecione `main` e a pasta `/ (root)`.
   - Clique em **Save**.
6. Espere 1–2 minutos. O GitHub vai te dar um link parecido com:
   `https://SEU-USUARIO.github.io/yvideo/`

Abra esse link — os vídeos tocam embutidos, com o player oficial do YouTube, sem nenhuma restrição.

## O que funciona no site
- Busca por título
- Filtro por categorias (topo e barra lateral)
- Envio de novos vídeos (cole um link do YouTube)
- Curtir / descurtir
- Salvar / favoritos
- Compartilhar (copia o link real do YouTube)
- Comentários
- Modo "PRO" (só decorativo, de brincadeira)
- Prévia animada ao passar o mouse nas miniaturas
- Player do YouTube tocando embutido na página de assistir
